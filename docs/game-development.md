# Game Development

Making a game (a "mod") for the Spring engine: units, weapons, models, animation, effects, UI, and Lua scripting. Modern development happens on [Recoil](https://recoilengine.org/), Spring's maintained fork — much of the material here still applies, but check the [Recoil docs](https://recoilengine.org/) for current APIs.
