# AI:Skirmish:List

<div class="mw-parser-output">

[Main Page](/main-page) \< AIs

Basics about [Skirmish AIs](/ai-skirmish) in Spring.

#### Under Active Development

Listed in alphabetical order.

**[AAI](/ai-aai)**  
config-based, C++, uses learning techniques, by Submarine

<!-- -->

**[BAI](/ai-bai)**  
config-less, Java, BA only, by Petah

<!-- -->

**[BKPAI](/ai-bkpai)**  
config-less, C++, Kernel Panic only, by Baczek

<!-- -->

**[Spring_Tanks](/spring-tanks)' Borked Advancer**  
config-less, Lua, Spring Tanks only, by knorke

(Spring Tanks included AI is hardly an "intelligence" but might be usefull if you want to look at an example of a very bare-bones Lua AI. The file is Gadgets\tpAIbork.lua)

**C.R.A.I.G.**  
config-based, Lua, currently <a href="http://spring1944.net/" class="external text" rel="nofollow">Spring 1944</a> and <a href="http://www.imperialwinter.com/" class="external text" rel="nofollow">SWIW</a> only, by Tobi

<!-- -->

**<a href="https://github.com/cranphin/crans-java-ai" class="external text" rel="nofollow">CransJavaAI</a>**  
config-less, Java, port of KAIK, by cranphin

<!-- -->

**<a href="http://code.google.com/p/spring-djai/" class="external text" rel="nofollow">DJAI</a>**  
config-based, Java, by DJ

<!-- -->

**<a href="http://springrts.com/phpbb/viewtopic.php?f=15&amp;t=19450" class="external text" rel="nofollow">E323AI</a>**  
config-based, C++, plays XTA, BA & BOTA by <a href="http://springrts.com/phpbb/memberlist.php?mode=viewprofile&amp;u=4131" class="external text" rel="nofollow">Error323</a> & <a href="http://springrts.com/phpbb/memberlist.php?mode=viewprofile&amp;u=6441" class="external text" rel="nofollow">Simon Logic</a>

<!-- -->

**[HughAI](/ai-hughai)**  
config-based, Java, port of CSAI, by Hugh Perkins

<!-- -->

**[KAIK](/ai-kaik)**  
config-less, C++, best suited for \*A mods, based on [KAI](/kai) by Krogothe, now developed by <a href="http://springrts.com/phpbb/memberlist.php?mode=viewprofile&amp;u=3405" class="external text" rel="nofollow">Kloot</a>

<!-- -->

**<a href="http://springrts.com/phpbb/viewtopic.php?f=55&amp;t=28259" class="external text" rel="nofollow">NOE</a>**  
config-based, Lua, AI for NOTA, gadget AI ready to use, developed by <a href="http://springrts.com/phpbb/memberlist.php?mode=viewprofile&amp;u=9850" class="external text" rel="nofollow">PepeAmpere</a>. Widget version planned. Small <a href="http://code.google.com/p/nota/wiki/NOE_introduction" class="external text" rel="nofollow">manual on project Wiki</a>.

<!-- -->

**[NTai](/ai-ntai)**  
config-based, C++, the longest running AI, currently non-functional, by AF

<!-- -->

**[RAI](/ai-rai)**  
config-less, C++, supports many mods due to its universality, by <a href="http://springrts.com/phpbb/memberlist.php?mode=viewprofile&amp;u=2771" class="external text" rel="nofollow">Reth</a>

<!-- -->

**[Shard](/ai-shard)**  
config-based, C++ & Lua, highly configurable/adjustable, by AF

#### Special

**[NullAI](/ai-nullai)**  
C Test AI, does nothing\

**[NullJavaAI](/ai-nulljavaai)**  
basic Java Test AI, does nothing\

**[NullLegacyCppAI](/ai-nulllegacycppai)**  
Legacy C++ Test AI, does nothing\

**[NullOOJavaAI](/ai-nulloojavaai)**  
Java Test AI using the OO wrapper, does nothing\
