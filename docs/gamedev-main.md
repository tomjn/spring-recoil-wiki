## Game Development

This information is meant to help newcomers learn how to develop their own games for the Spring Engine. If you are interested in creating maps for Spring, see [Mapdev:Main](/mapdev-main).

## Templates & Examples

- [SpringABC](/gamedev-springabc) - A hierarchical set of empty template games, without examples
- [Spring Tutorial Game](/springtutorialgame) - A tutorial template game with full examples
- [Public Repos](/gamedev-publicrepos) - Publicly readable Spring game code repositories

## Technical Documentation

### GameData

- [Armordefs.lua](/armordefs.lua) - armor classes
- [Icontypes.lua](/icontypes.lua) - strategic unit icons
- [Modinfo.lua](/modinfo.lua) - game identifier file (name, version,...)
- [Modrules.lua](/modrules.lua) - Global game variables
- [Movedefs.lua](/movedefs.lua) - MoveClasses for pathfinding
- [Resources.lua](/resources.lua) - index file for textures
- [Sidedata.lua](/sidedata.lua) - playable factions/races/sides
- [Sounds.lua](/sounds.lua) - index file for sounds
- [Messages.lua](/messages.lua) - Team death messages New in version 95.0:deprecated

### Definition Files

- [Gamedev:UnitDefs](/gamedev-unitdefs) - define the attributes of units
- [Gamedev:WeaponDefs](/gamedev-weapondefs) - define the attributes of weapons/projectiles
- [Gamedev:FeatureDefs](/gamedev-featuredefs) - define the attributes of static map features and wrecks
- [CEG:Main](/ceg-main) Particle effects (explosions etc)
