# About this wiki

This is an independent, community-maintained rebuild of the [springrts.com wiki](https://springrts.com/wiki/), covering the **Spring** RTS engine and its actively-developed fork, **Recoil**.

## Why this exists

The original wiki is a classic MediaWiki install that has fallen into neglect: broken links, out-of-date pages, poor structure, and it is now gated behind anti-bot software that makes it awkward to read and to work with using modern tooling. This rebuild aims to be portable (plain Markdown), searchable, better organised, and pleasant to read.

It is a **one-time import**. There is no ongoing synchronisation with the source wiki, which is considered dead by most of the community.

## Content, licensing and attribution

The source wiki declares its content to be released **into the public domain** (see the original [Spring:Copyrights](https://springrts.com/wiki/Spring:Copyrights) page). Every page here links back to the springrts.com page it was imported from, at the bottom of the page, to preserve provenance and credit the original contributors.

The Spring engine itself is licensed GPL; games/mods carry their own licenses. Those licenses are unaffected by this wiki.

The site tooling, configuration and theme (everything that isn't imported wiki content) is MIT-licensed.

## Status

This is a faithful first pass: pages were converted mechanically from the source. Some pages are outdated, some links point to pages that never existed on the original wiki, and a handful of images that were already broken on the source remain broken here. Restructuring, pruning and modernisation are ongoing.
