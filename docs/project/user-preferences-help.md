# Spring:User preferences help

<div class="mw-parser-output">

Use the User Preference page to edit preferences for your profile. There are a few sections to the User Profile, each of which will be covered in detail here.

## User data

### Your real name

If you so desire, enter your real name into this box. Other people will be able to see your name, and know its you. This setting is optional.

### Your Email

If you want people to be able to email you, enter your Email address in this box. This email address will not be given to the person trying to email you, instead they will write a message that will be forwarded to you.

### Your nickname

Enter your nickname here. This is the name that will be appended to the end of your posts if you so desire.

### Raw signatures

If selected, this will post your signature as plain text, instead of linking to your user page.

### Interface language

From the drop-down box, select your prefered language. There are many languages to choose from, so you should feel right at home.

### Change password

Use these boxes to change your password. You will need your old password, and a new password to change your password.

### Remember password across sessions

Select this option to automatically log into the wiki everytime you visit it. Not recommended for shared computers.

## Quickbar

Choose to enable the 'Quick-bar', and where to position it. Default is down the bottom.

## Skin

Choose from a variety of skins.

## Rendering math

Choose how you want mathematical forumae to be drawn.

## Editing

Change these options to change how pages are edited.

### Rows & Columns

Change the size of the editing box. A good size is 25 by 80.

### Edit box has full width

Select this to make the edit box the full width of the page.

### Show edit toolbar

Enables/Disables the editing toolbar at the top of the edit window.

### Show preview on first edit

Select this to automatically show a preview of your work the first time you save it.

### Show preview before edit box and not after it

Choose if the page preview appears after the edit box, or before it.

### Add pages you edit to your watchlist

Select this to automatically add all the pages you edit to your watch list.

### Mark all edits minor by default

Choose this to mark all edit minor, unless specified otherwise.

## Time zone

Change the time displayed on the pages. I think server time is GMT -1.

## Recent changes and stub display

### Number of titles in recent changes

Change the default number of recent changes to display on the Recent Changes page.

### Hide minor edits in recent changes

Select this to hide edits labeled 'minor' in the Recent Changes page.

### Enhanced recent changes

Make the Recent Changes page look really spiffy. This option is not for all browsers, as some have difficulty rendering it.

### Threshold for stub display

Changes the threshold of stub article display. NFI what that actually means, but...

### Limit images on image description

Choose how big the biggest an image can be on an Image Description page.

## Search result settings

### Hits to show per page

Change how many hits are displyed by default in the search results.

### Lines to show per hit

Lines to show per search hit.

### Characters of context per line

How many characters are show of the page content per hit.

### Search in these namespaces by default

Choose which sections to search by default. The options are:

- Main
- Talk
- User
- User talk
- Spring
- Spring talk
- Image
- Image talk
- MediaWiki
- MediaWiki talk
- Template
- Template talk
- Help
- Help talk
- Category
- Category talk

## Misc settings

### Show hoverbox over wiki links

Choose whether to show a tooltip over links or not.

### Underline links

Choose whether links are underlined or not.

### Broken Link Format

Choose how broken links are formatted.

### Justify paragraphs

Choose whether to have normal or justified paragraphs.

### Auto-number headings

Choose whether headings are automnatically preceded by a number or not.

### Edit pages on double click (JavaScript)

Turn this on to be able to edit a page by double clicking on it.

### Enable section editing via \[edit\] links

Turns the little \[edit\] links besides heading on and off.

### Enable section editing by right clicking on section titles

Turns on or off the ablilty to edit sections by right clikcing on them. Javascript must be enabled for this to work correctly.

### Show table of contents

Choose this to show a table of contents when there is more than 3 sections in a page.

### Disable page caching

Choose this to disable page caching. Dunno what page caching is, but you can diasable it!
