# Slackware install

> **Historical:** This page described installing classic Spring (0.82-89.0 era) on Slackware via SlackBuilds and hand-hosted packages. Every download link (corec.cl, MegaUpload, Dropbox, springfiles) is long dead, so the guide is no longer usable.

For a current game on Linux, install [Beyond All Reason](https://www.beyondallreason.info/). To build the engine from source, see the [RecoilEngine repository](https://github.com/beyond-all-reason/RecoilEngine/) and the general [Linux build guide](/building-spring-on-linux).
