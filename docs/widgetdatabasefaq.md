# WidgetDatabaseFAQ

> **Historical:** The Spring "widget database" was community infrastructure that is no longer relevant to current engines. For Lua widget development see [Lua Scripting](/lua-main); for the modern game's widget ecosystem see [Beyond All Reason](https://www.beyondallreason.info/).

The widget database was an online, HTTP-accessible collection of most Lua widgets ever released for the Spring engine. It was reachable through several lobby clients and a dedicated .NET "WidgetManager" application. The service (`widgetdb.springrts.de`) and its clients are defunct.
