## What is the widget database?

The widget database is a resource which contains most of the widgets that got ever released for the Spring engine. The database is stored online and can be accessed via an HTTP interface. There are many different clients available to access the database. These are the most common:

## For widget developers

If you want to see your widgets added to the widget DB, you can get an admin account for the database, which will enable you to add/edit/remove your widgets. Just PM <a href="http://springrts.com/phpbb/memberlist.php?mode=viewprofile&amp;u=5267" class="external text" rel="nofollow">me (very_bad_soldier)</a>, and I will provide all you need. Big thanks to manolo\_ at this point, who helped a lot in keeping the database up to date in the last few years!

<a href="http://springrts.com/phpbb/viewtopic.php?f=23&amp;t=16122" class="external text" rel="nofollow">Widget database announcement thread</a>
