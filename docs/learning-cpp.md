# Learning CPP

<div class="mw-parser-output">

If you're interested in learning C++, check out these links:

- <a href="http://newdata.box.sk/bx/c/" class="external text" rel="nofollow">Teach Yourself C++ in 21 Days</a> is an excellent introduction for anybody new to the language. It teaches you the bare minimum you can get away with.
- <a href="http://mindview.net/Books/TICPP/ThinkingInCPP2e.html" class="external text" rel="nofollow">Thinking in C++</a> An excellent, thorough C++ book available free online as HTML. Also available in <a href="http://www.planetpdf.com/developer/article.asp?ContentID=6634" class="external text" rel="nofollow">PDF format</a>.
- <a href="http://www.parashift.com/c++-faq-lite/" class="external text" rel="nofollow">C++ FAQ</a> An excellent guide to the many problems encountered when writing C++ and how to avoid them.
- <a href="http://www.amazon.com/exec/obidos/tg/detail/-/0130384747/002-6409742-5712035?v=glance" class="external text" rel="nofollow">C++ How to Program</a> Although it's a commercial volume, it is an excellent introduction to the language.

If the above aren't enough there are links to more free C++ books here: <a href="http://www.freeprogrammingresources.com/cppbooks.html" class="external free" rel="nofollow">http://www.freeprogrammingresources.com/cppbooks.html</a>.

For humour you might be interested in: <a href="http://www.lysator.liu.se/c/ten-commandments.html" class="external text" rel="nofollow">The Ten Commandments for C Programmers</a> (C++ is based on C). However the advice given should be taken with a pinch of salt!
