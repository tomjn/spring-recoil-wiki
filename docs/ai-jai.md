# AI:JAI

> **Deprecated:** JAI has been superseded by the [Java AI Interface](/aiinterface-java). For current AI development see [AI Development](/ai-development).

JAI was a Java wrapper (by hoijui) for Spring's old GlobalAI interface, letting AIs be written in Java. It was not an AI itself. It was built against the legacy C++ AI interface and required SVN builds of Spring circa mid-2008 (tested with spring r5956); it was always intended to be ported to the newer C AI interface, which is what the maintained [Java AI Interface](/aiinterface-java) provides today. The original SVN-era build and setup instructions are obsolete and have been removed.
