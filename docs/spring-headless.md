# Spring Headless

<div class="mw-parser-output">

spring-headless is a console program which allows to run spring without a gfx card to run for example ai vs ai-games without user in or output.

to setup spring-headless copy springrc-template-headless.txt to ~/.[springrc](/springsettings.cfg) (or springsettings.cfg).

create a script.txt and run it with spring-headless [script.txt](/script.txt) (note: you can set up a game in SpringLobby - after you have started a game, Spring will have written the configuration to the file script.txt in your Spring folder).
