# AIInterface:Python

<div class="mw-parser-output">

Important note: in current spring/master it is currently disabled because of an recently big merge (pureint), it will be fixed soon!

## Spring PyAI

The Spring PyAI Interface can be used to write a skirmish AI in Python. Look at the [Development Page of Python](/ai-development-lang-python) if you want write an AI.

### Code

<a href="http://github.com/spring/Python" class="external free" rel="nofollow">http://github.com/spring/Python</a>

### Building

The Python Interface is in spring/master, just git clone it, run "git submodule init" and you can compile/install it!

## Known Issuses/TODO
