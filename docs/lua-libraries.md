# Lua Libraries

## Lua libraries

This page lists all common Lua libraries that can be used in Spring game and map archives.

Libraries:

- <a href="https://github.com/gajop/analytics" class="external text" rel="nofollow">analytics</a>: Usage analytics reporting
- <a href="https://github.com/jk3064/chiliui" class="external text" rel="nofollow">ChiliUI</a>: UI framework [docs](/chili)
- <a href="https://github.com/gajop/chilifx" class="external text" rel="nofollow">ChiliFX</a>: Chili effects
- <a href="https://github.com/gajop/chotify" class="external text" rel="nofollow">Chotify</a>: Notification library in Chili
- <a href="https://github.com/jk3064/Custom-Unit-Shader-Framework" class="external text" rel="nofollow">Custom Unit Shader Framework</a>: Unit rendering with shaders
- <a href="https://github.com/gajop/i18n" class="external text" rel="nofollow">i18n</a>: Translations library
- <a href="https://github.com/gajop/liblobby" class="external text" rel="nofollow">LibLobby</a>: Spring Lobby protocol library
- <a href="https://github.com/gajop/Lua-Class-System" class="external text" rel="nofollow">LCS</a>: OOP (classes) in Lua
- <a href="https://github.com/jk3064/lups" class="external text" rel="nofollow">LUPS</a>: Lua Particle System for Spring [docs](/lups)
- <a href="https://github.com/gajop/springmon" class="external text" rel="nofollow">springmon</a>: Spring file monitor and autoreloader
- <a href="https://github.com/gajop/spring-wrapper-connector" class="external text" rel="nofollow">spring-wrapper-connector</a>: Wrapper program communication provider

### Single file libraries

There is also a number of single file libraries that don't have their own repository but can technically still be considered libraries.

Library files:

- <a href="https://github.com/SpringMCLegacy/SpringMCLegacy/blob/master/LuaRules/Gadgets/api_vector.lua" class="external text" rel="nofollow">Vector</a>: Small utility for vector operations
- <a href="https://github.com/Spring-SpringBoard/SpringBoard-Core/blob/master/libs_sb/json.lua" class="external text" rel="nofollow">JSON</a>: Serializing to the JSON format
- <a href="https://github.com/spring1944/spring1944/blob/master/LuaRules/Gadgets/api_delay.lua" class="external text" rel="nofollow">Delay</a>: Delaying gadget calls
- <a href="https://github.com/spring1944/spring1944/blob/master/LuaRules/Includes/network.lua" class="external text" rel="nofollow">Network</a>: Delta compression for binary strings
- <a href="https://github.com/spring1944/spring1944/blob/master/LuaRules/Includes/camera.lua" class="external text" rel="nofollow">Camera</a>: Camera state serialization
- Deferred rendering <a href="http://imolarpg.dyndns.org/svn/branches/BAR/shaders/deferred_lighting.glsl" class="external text" rel="nofollow">Shader</a> & <a href="http://imolarpg.dyndns.org/svn/branches/BAR/luaui/widgets/gfx_deferred_rendering.lua" class="external text" rel="nofollow">Widget</a>: Deferred rendering (projectile) based lights

#### Misc

- <a href="http://springrts.com/phpbb/viewtopic.php?t&amp;t=28341" class="external text" rel="nofollow">ChangePiece</a> - Switch piece geometry
