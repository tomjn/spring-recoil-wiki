# Read Me First

<div class="mw-parser-output">

## Playing

**Spring is an engine!** It can play many different games and maps. To play, you need at least one [Game](/games) and [Map](/maps)!

### Getting Started

To get started with Spring, download <a href="https://springlobby.springrts.com/" class="external text" rel="nofollow">SpringLobby</a>, which you can use to play, chat and download games and maps.

### Downloading Games/Maps

**To download [Games](/games) (or [Maps](/maps)), use your lobby to join an online battle hosting the game/map that you want. It should offer to download for you.**

*If the download fails, or if no games/maps show up, you should check that your lobby has found your Spring install. With SpringLobby, click edit -\> preferences -\> Spring, and make sure that it has the correct paths.*

You can also download games and maps manually, see the [FAQ](/faq). There is also the option to install different [Lobbies](/gamesdownloads#universal-downloaders).

### Single-Player

To start a single-player game, use your lobby. Go to the Single-Player tab. Select a game, map and [AI](/ai-skirmish-list) and click "Start".

Some AIs don't work with all games. If the one you pick builds nothing, try another!

### Playing Online

To play online, you need the latest version of the [Spring Engine](/download). To join matches, look for the "battles" or "multiplayer" tab in your lobby client.

### Wondering where some former popular games are?

Some larger games run their own lobby servers!

- Zero-k (which grew out of CA) can be found at <a href="https://zero-k.info/" class="external free" rel="nofollow">https://zero-k.info/</a>
- Beyond All Reason (which grew out of BAR) can be found at <a href="https://www.beyondallreason.info/" class="external free" rel="nofollow">https://www.beyondallreason.info/</a>
- Balanced Annihilation and some other legacy \*A games can be found at at <a href="https://balancedannihilation.com/" class="external free" rel="nofollow">https://balancedannihilation.com/</a>
