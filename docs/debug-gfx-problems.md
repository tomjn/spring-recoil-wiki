# Debug GFX problems

<div class="mw-parser-output">

to debug GFX problems, you can use <a href="https://github.com/apitrace/apitrace" class="external text" rel="nofollow">apitrace</a>

If you are on windows and have an ATI card, <a href="http://developer.amd.com/tools/heterogeneous-computing/codexl/" class="external text" rel="nofollow">CodeXL</a> can be used.

Use <a href="https://springrts.com/phpbb/viewtopic.php?f=12&amp;t=33437" class="external text" rel="nofollow">Software Rendering</a> to find general errors.
