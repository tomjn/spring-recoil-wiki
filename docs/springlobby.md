# SpringLobby

<div class="mw-parser-output">

cross-platform, C++, by abma

SpringLobby is the official lobby client of spring and is bundled with the Spring engine in the installer. It uses the *wxWidgets* library.

## Download

<a href="https://springlobby.springrts.com" class="external free" rel="nofollow">https://springlobby.springrts.com</a>

## Source Code

<a href="https://github.com/springlobby/springlobby/" class="external text" rel="nofollow">Springlobbies source code</a> is at github. When not using git please use tarballs from the official site as githubs automaticly created tarballs are broken.

## Bugs

Please report bugs to <a href="https://github.com/springlobby/springlobby/issues" class="external text" rel="nofollow">Springlobby's official bug tracker</a>.

When reporting bugs, please provide [springlobby.log](/springlobby.log)!
