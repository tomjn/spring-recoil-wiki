# Matrix

<div class="mw-parser-output">

Matrix is an open network for secure, decentralized communication. Spring has its own matrix server which is connected with [Glenda](/glenda) to the lobby server.

A lobby account is required to login: <a href="https://springrts.com/matrix/" class="external free" rel="nofollow">https://springrts.com/matrix/</a>

#### Matrix Server

- synapse: <a href="https://github.com/matrix-org/synapse" class="external free" rel="nofollow">https://github.com/matrix-org/synapse</a>
- authprovider: <a href="https://github.com/TurBoss/matrix-synapser-uberserver-xmlrpc" class="external free" rel="nofollow">https://github.com/TurBoss/matrix-synapser-uberserver-xmlrpc</a>

#### Matrix - Uberserver Bridge

- framework: <a href="https://github.com/tulir/mautrix-python" class="external free" rel="nofollow">https://github.com/tulir/mautrix-python</a>
- lobby library: <a href="https://github.com/TurBoss/asyncspring" class="external free" rel="nofollow">https://github.com/TurBoss/asyncspring</a>
- appservice: <a href="https://github.com/TurBoss/matrix-spring-appservice" class="external free" rel="nofollow">https://github.com/TurBoss/matrix-spring-appservice</a>, <a href="https://github.com/half-shot/matrix-appservice-discord" class="external free" rel="nofollow">https://github.com/half-shot/matrix-appservice-discord</a>
