### Scripting And Unit Stats files

1.  **<a href="http://springfiles.com/spring/tools/scriptor-v1" class="external text" rel="nofollow">Scriptor</a>**\*\*\
    -\> The by far best compiler for your handmade .bos scripts into endless lines of letters and numbers that the TA engine reads. The program is large, easy to operate and with broad error tracing (well, better than the other two alternatives). While other versions of this program sometimes refuse to compile on-off functions, this download is guaranteed to work in every condition.
2.  **<a href="http://springfiles.com/spring/tools/cobbler-v4" class="external text" rel="nofollow">Cobbler</a>**\*\
    -\> This is a very simple script compiler that converts your newly written .bos files understood by humans into a hexadecimal .cob gibberish used by the TA engine. Beware, however, that this program may fail to compile some perfectly valid scripts and it doesn't always tell where the alleged error lies either. Parts of the program are in French.
3.  **<a href="http://springrts.com/phpbb/viewtopic.php?f=9&amp;t=24702&amp;p=460639" class="external text" rel="nofollow">Servo</a>**\*\
    -\> Rhad's awesome but somewhat buggy animation scripting program. It features keyframed animation script generation from a 3D positioner.
4.  **<a href="https://github.com/Anarchid/blender2lus" class="external text" rel="nofollow">blender2lus</a>**\*\*\
    -\> A Blender addon that allows Spring lua unitscripts (for assimp models only) to be authored in Blender, with (almost) all the goodies involved therein.
5.  **<a href="http://springrts.com/phpbb/viewtopic.php?f=14&amp;t=25104" class="external text" rel="nofollow">Spring Poser by knorke</a>** A not-yet-so-usefull gadget-widget-unitscript brewage that allows you to "pose" units by moving & rotating their pieces. It can then save the posed position as a list of Move & Turn commands.
6.  **<a href="http://springrts.com/phpbb/viewtopic.php?f=23&amp;t=24499" class="external text" rel="nofollow">CEG Browser/Spawn by CarRepairer</a>** Spawn particle effects from a menu, ie if you want to reuse effects from another game.
7.  **<a href="http://springrts.com/phpbb/viewtopic.php?f=23&amp;t=25847" class="external text" rel="nofollow">piece tree widget</a>** Print an ascii view of a units piece hierachy. Might be usefull to create notes for scripting.
8.  **<a href="http://springrts.com/phpbb/viewtopic.php?f=67&amp;t=23391" class="external text" rel="nofollow">bos2lua converter page by CarRepairer</a>** Converts .bos scripts to .lua scripts.
9.  **[ToolBox](/toolbox)** A game-mutator with some tools for modding. Contains newest version of some of the above scripts plus others.

### Map Creation

1.  **[SpringMapEdit](/maps-springmapedit)**\*\*\
    -\> Our very own complete map making solution, created by Frostregen.
2.  **<a href="http://www.springfiles.com/show_file.php?id=2441" class="external text" rel="nofollow">Beherith's mapconv</a>**\*\*\
    -\> The latest map compiler, supports all features of maps while still retaining backwards compatibility with previous scripts.
3.  **<a href="https://springrts.com/phpbb/viewtopic.php?t=2420" class="external text" rel="nofollow">SMD Creator</a>**\*\*\
    -\> Maelstroms SMD creator
4.  **<a href="http://www.bundysoft.com/L3DT/" class="external text" rel="nofollow">L3DT Large 3D Terrain Generator</a>**\*\*\
    -\> Commercial Map Maker, standard version is free, but pro version requires payment but includes all the tools required to make an SD7 Spring map from scratch.
5.  **<a href="http://code.google.com/p/conflictterra/wiki/MapsAndRocks#Coordinate_Helper_Widget" class="external text" rel="nofollow">Coordinate helper widget</a>** Need to find lots of coordinates, for example to position units? Log the coordinates into a file just by placing markers, no more pen&paper!
6.  **<a href="http://www.world-machine.com/" class="external text" rel="nofollow">World Machine</a>** Commercial terrain generation software, can output height and diffuse textures.
7.  **<a href="http://en.wikipedia.org/wiki/Bryce_(software)" class="external text" rel="nofollow">Bryce3D</a>** Shareware terrain generation software.
8.  **<a href="http://en.wikipedia.org/wiki/Carrara_(software)" class="external text" rel="nofollow">Carrara</a>** Shareware 3D software.
