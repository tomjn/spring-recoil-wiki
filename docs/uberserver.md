# Uberserver

<div class="mw-parser-output">

uberserver is a lobbyserver written in python for spring lobby clients.

its currently used as the main lobby server running at lobby.springrts.com port 8200.

its the home of the server bot [ChanServ](/chanserv)

see <a href="https://github.com/spring/uberserver" class="external free" rel="nofollow">https://github.com/spring/uberserver</a> for more details
