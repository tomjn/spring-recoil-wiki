# MiniSpring

> **Historical:** MiniSpring is a deprecated Spring engine variant and does not run on current engines. See [Games](/games) for playable games.

MiniSpring was a special release of the Spring engine by Buggi that halved the size of all units, making maps look and feel twice as large as they really are. Because it relied on a modified executable and a very old engine version (0.65b2), it was incompatible even with the lobby clients of its own era, and it does not work with modern Spring or Recoil. Kept for historical reference.
