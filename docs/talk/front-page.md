As others mentioned on the Forums, this page design looks like it might be good for the main site front page, but isn't really good for the *Wiki* front-page. That said, the old Wiki front page could use a bit of a redesign. Right now, it's not really obvious what a newbie wants to read, and the categories seem a little arbitrary. Perhaps a better set would be:

Spring (Read Me First, Getting Started, Using Spring, Spring On A LAN, Strategy and Tactics, Features, FAQ, Spring Project, Related Software) - Also might be worth changing "Related Software" to, say, "Lobby Clients", since there appear to be a bunch in development.

Community (Clans, King Titles, Mods, Maps, Monthly Topic Rotation, Add to the Wiki)

Modding (Mod Development, Unit Development, Create Units, Create Maps, Map, Mod, And Unit Development Programs)

Development (Source Development, Linux, Mac, AI)

It could be split into two rows, one for Spring and Community, one for Modding and Development.

Thoughts?
