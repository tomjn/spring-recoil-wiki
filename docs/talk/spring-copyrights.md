# Spring talk:Copyrights

<div class="mw-content-ltr mw-parser-output" lang="en" dir="ltr">

Some time ago I put a disclamer on the [Main_Page](/main-page) that all contributions to this wiki are in the public domain. This can be changed to GPL but maybe it's a good idea to talk this over?

Sinbadev: What's the difference... Public domain people are allowed using it without crediting right? is their a GNU/GPL etc that would basically allow them to quote the source site... because this place reallyt doesn't have a specific author... I've corrected, words, phrases, punctuation and has the same done for me... it's all very collective.. what do other wiki's use?

Public domain is do what you like with it, nobody has the rights to the work.\
You don't need to quote the author with gpl.\
Other wiki's use GFDL, GPL, CC, Nothing, and all rights go to site owner.\

I think Public Domain is best at the moment as that way we can change it later, that is not posible with the GPL.\

-- Tim Blokdijk

I changed the copyright page to keep it inline with the statement on the [Main_Page](/main-page) we can alway's change it to GPL or anything later.
