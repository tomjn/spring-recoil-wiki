# SpringLS

<div class="mw-parser-output">

SpringLS is a lobbyserver written in java. It can be run in LAN-Mode which allows logging in without creating an account. Its a replacement of <a href="http://springrts.com/dl/TASServer.jar" class="external text" rel="nofollow">TASServer</a> which is unmaintained.

## Setup

To run SpringLS you need to install the <a href="http://www.java.com/en/download/manual.jsp" class="external text" rel="nofollow">Java Runtime Environment</a>.

Once that is installed, you need to setup the lobby server.

See the <a href="https://github.com/spring/SpringLS/blob/springls-0.37/README.markdown" class="external text" rel="nofollow">README</a> for more info.
