## Default Keyboard Layout in Spring

Note: This page is currently incomplete and different games might use different keyboard configurations. But this page covers the basics which are broadly common to most Spring games.

<col>

<tr>
<td>Mouse 1 (left)</td>
<td>Selecting units, selecting orders/buildings from the menu and also to give orders!</td>
</tr>
<tr>
<td>Mouse 2 (right)</td>
<td>Give the default order (move). Or change from a non-default order (e.g. attack, fight, guard) back to a move order without giving an order.</td>
</tr>
<tr>
<td>Scroll Wheel</td>
<td>Zoom in/out</td>
</tr>
<tr>
<td>Mouse 3</td>
<td>Pan camera (mouse 2 is normally pressing the scroll wheel)</td>
</tr>
<tr>
<td>SHIFT</td>
<td>Queue order. Press shift as you give the order, queue up as many as you like! Press Ctrl/Alt as well for building formations.</td>
</tr>
<tr>
<td>[ and ]</td>
<td>Rotate building (first select something to build and then rotate)</td>
</tr>
<tr>
<td>A</td>
<td>Attack (attack unit/ground)</td>
</tr>
<tr>
<td>M</td>
<td>Move</td>
</tr>
<tr>
<td>F</td>
<td>Fight (as move, but units will stop to kill enemies along the way)</td>
</tr>
<tr>
<td>G</td>
<td>Guard</td>
</tr>
<tr>
<td>P</td>
<td>Patrol. (Moves back and forth between current position and patrol position)</td>
</tr>
<tr>
<td>S</td>
<td>Stop (cancels all orders)</td>
</tr>
<tr>
<td>E</td>
<td>Reclaim (Eat!)</td>
</tr>
<tr>
<td>R</td>
<td>Repair</td>
</tr>
<tr>
<td>D</td>
<td>D-Gun (or other manual fire weapon)</td>
</tr>
<tr>
<td>K</td>
<td>Cloak on/off</td>
</tr>
<tr>
<td>CTRL + D</td>
<td>Self Destruct</td>
</tr>
<tr>
<td>W</td>
<td>Wait (or stop waiting)</td>
</tr>

<td>CTRL + number (1-0)</td>
<td>Assign using to group</td>
</tr>
<tr>
<td>number (1-0)</td>
<td>Select unit group</td>
</tr>
<tr>
<td>Double Click</td>
<td>Select all units of targetted type in view</td>
</tr>
<tr>
<td>CTRL + Z</td>
<td>Select all units of selected type on map.</td>

<td>Select all units on map.</td>

<tr>
<td>TAB</td>
<td>Zooms out to see the whole map.</td>
</tr>
<tr>
<td>F1</td>
<td>Shows heightmap</td>
</tr>
<tr>
<td>F2</td>
<td>Shows areas where you can build (if the building what you want to build is selected)</td>
</tr>
<tr>
<td>F3</td>
<td>Goes to the latest spot of action (also goes to the latest markers)</td>
</tr>
<tr>
<td>F4</td>
<td>Shows metalmap</td>
</tr>
<tr>
<td>F5</td>
<td>Hides User Interface</td>
</tr>

<td>CTRL+F1/2/3/4</td>
<td>Change camera mode</td>
</tr>
