# Bugs

<div class="mw-parser-output">

## See if the bug and a solution are already known

Check that it isn't already visible somewhere near the top of the relevant bugtracker:

<a href="https://springrts.com/mantis" class="external text" rel="nofollow">Spring Engine bugtracker (mantis)</a>

<a href="https://github.com/springlobby/springlobby/issues" class="external text" rel="nofollow">Spring Lobby (github)</a>

<a href="https://github.com/dansan/spring-replay-site/issues" class="external text" rel="nofollow">Replay Site (github)</a>

Or see the relevent project pages for links to other bug trackers. There is also a <a href="https://springrts.com/phpbb/viewforum.php?f=11" class="external text" rel="nofollow">helps and bugs forum</a>.

## How to report bugs

To report a bug, please give a description, what is going wrong and **how it can be reproduced**. what steps are required to reproduce it? If required to reproduce the bug add a script or/and a link to the Game/Map.

## Logfiles, screenshots, replays

- It is best to always attach [infolog.txt](/infolog.txt), as it contains system/driver/version info and a stacktrace if spring crashed.

<!-- -->

- Attach a replay: often Bugs can't be reproduced, its often better to see something than to only read about that.

<!-- -->

- Screenshots are taken with the F12 key and saved in the \screenshots\\ folder. You can attach them to postings or upload on site such as: <a href="http://www.imgur.com" class="external text" rel="nofollow">imgur.com</a> , <a href="http://www.abload.de" class="external text" rel="nofollow">abload.de</a>

If a dev asks you for more information, please answer his questions. Try to avoid endless discussions why a bug was introduced, be polite!

If you want more tips for a good bug-report, please read "<a href="http://www.chiark.greenend.org.uk/~sgtatham/bugs.html" class="external text" rel="nofollow">How to Report Bugs Effectively</a>" **The better the bug-report, the better the chances, that it will be fixed!**

## Where to report bugs

Bugs in individual games should be reported to the game developers - contact the game developer first if you are unsure.

### As a player who needs help or thinks they found a bug

Do not be afraid to ask for help <a href="http://springrts.com/phpbb/viewforum.php?f=11" class="external text" rel="nofollow">in the forum.</a> Read the guidelines above so people can help you as good as possible.

### As a developer who found a bug

If you found a bug in the Spring Engine, please report it to the <a href="http://springrts.com/mantis" class="external text" rel="nofollow">bug tracker</a>. Before <a href="http://springrts.com/mantis/bug_report_page.php" class="external text" rel="nofollow">filling a bug</a>, please look if someone else <a href="http://springrts.com/mantis/view_all_bug_page.php" class="external text" rel="nofollow">already has reported</a> this issue.

Also please:

1.  disable LuaRules/LuaUI for testing
2.  debug all relevant Lua callins

Bugs should be reported for latest release version and latest develop version.
