The **Xect vs. Mynn** Mod, aims to be a completely free (as in GNU <a href="http://www.gnu.org/copyleft/gpl.html" class="external text" rel="nofollow">GPL</a>) data package for the Spring engine.

</div>

## History

This mod was initialy created by Chris Jorgensen <a href="http://www.xenoclone.com/" class="external free" rel="nofollow">http://www.xenoclone.com/</a> for the original Total Annihilation engine. For the Spring engine Chris Jorgensen decided to release his work under the GNU GPL so others could port it. Michilus Nimbus made the first port that did not crash on startup. FoeOfTheBee has made it somewhat playable, and probably GPL.
