## Plasma

The plasma system can be used to download a specific file by filename

<a href="http://zero-k.info/ContentService.asmx" class="external free" rel="nofollow">http://zero-k.info/ContentService.asmx</a>

Its a soap-service, the service-name for downloading is "DownloadFile".

It returns a torrent file and a list of mirrors. This allows parallel downloads and pieces can be checked with the torrent file. A torrent file is a bencoded file.

An <a href="http://zero-k.info/ResourceList.aspx" class="external text" rel="nofollow">admin-interface</a> is also available.
