# Help:Editing

<div class="mw-parser-output">

This page contains tips on editing wiki pages, for full details of editing the Wiki see <a href="http://meta.wikipedia.org/wiki/MediaWiki_User%27s_Guide" class="external text" rel="nofollow">User's Guide</a>

## Basic Editing

- Choose what you want to do:
  1.  **Make a new page**\
      Type the URL of the page you want to create into the address bar.\
      EG: /wiki/Page_that_doesnt_exist
  2.  **Edit an existing page**\
      Goto the page you want to edit, either through Links, or a URL.
- Then, click the 'Edit this page' link at the bottom.
- A page with a text box in the middle of it will appear.
- Enter text into this box.
- To insert formatting, click the formatting buttons above the text box.
- For a full list of formatting tags, and their effects, see below
- Click the 'Preview Page' button below the text box to preview the page.
- Fix any errors you spot.
- Click 'Save page' next to the Preview button.
- You're Done!

Dont worry if you stuff things up. Its very easy to fix. Any changes that are made are automatically logged, and we can easily revert to an old version if you totally screw a page up. And if your still worried of messing something up, you can always play around in your own user page first.

### Posting code

    If (not horse) then
     GameOver()
    end

use like:

\<code\>\<pre\>CODE HERE\</pre\>\</code\>

\<code\> tags alone fails sometimes.
