# Strategy:Absolute Annihilation

<div class="mw-parser-output">

## Game Strategy

Absolute Annihilation is a modification of TA. Therefore, the same basic strategies and tactics that good TA players utilize are also utilized by good AA players. Although the best players heavily analyze famous military works such as *The Art of War*, the essence of the message lies in the following points:

1.  Always Expand
2.  Be Offensive
3.  Practice

Indeed, the actual units present in AA are irrelevant; it takes little time to learn what they all do. The key lies in utilizing them effectively. Always keep the following points in mind when playing, and above all, practice, and even if you lose, ask the person to whom you lost what you did wrong and right.

## Strategies and their counters

This is a list of strategies, and a good way to counter them

|  |  |
|----|----|
| **Strategy** | Counter |
| **Skirmishers** | Planes, heavy defenses with a fair bit of range |
| **Stationary Defenses** | Mid range units with jammers and radar or scouts |
| **Arty** | Jammers |
| **Jammers** | Scouts |
| **Defense Swarming** | Mass Expansion |
| **Mass Expansion** | Mass Raiding |
| **Unit Swarming** | Defense Swarming ( reclaim wrecks) |
| **Commander** | Radar Skirmish |
| **Level One Swarming** | Defense Swarming, Microed L2 (especially skirmishers) |
| **Heavy Short Range Defenses** | Assault Units (slow but powerful), long range units with radar or scouts |
| **Assault Units** | Heavily raid his econ to cripple production (air are good), brawlies, lvl1 short range (cost effective but you need a load of them) |
| **Porcers** | Porc more, it annoys Kelson which is always fun |
